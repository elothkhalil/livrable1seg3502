# Notifications et intégrations météo

Classification : **Générique**.

L’envoi fiable de courriels et l’accès à une prévision sont des capacités techniques réutilisables. Le cœur détermine les événements déclencheurs et les destinataires.

## Responsabilité
Confirmer, notifier les promotions/annulations et envoyer les rappels.

## Concepts candidats
Notification, clé de déduplication, état de livraison, prévision facultative.

Voir le rapport (section 5) pour les invariants et les dépendances.
