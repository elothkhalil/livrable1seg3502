# Référentiel externe des sentiers

Classification : **Support**.

La CCN fait autorité; le club adapte et consulte ses données sans éditer un catalogue indépendant.

## Responsabilité
Fournir les caractéristiques utiles à la planification et à la consultation.

## Concepts candidats
Référence CCN, instantané horodaté, difficulté, permission et saison.

Voir le rapport (section 5) pour les invariants et les dépendances.
