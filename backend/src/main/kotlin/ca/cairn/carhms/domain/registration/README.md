# Inscriptions et liste d’attente

Classification : **Cœur**.

L’appariement des membres aux événements, les limites de niveau et la promotion FIFO constituent la différenciation recherchée par le client (§1.2).

## Responsabilité
Inscrire, annuler une inscription et promouvoir sans dépasser la capacité.

## Concepts candidats
Inscription, statut, rang FIFO et attribution des places.

Voir le rapport (section 5) pour les invariants et les dépendances.
