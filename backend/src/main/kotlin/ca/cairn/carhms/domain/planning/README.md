# Planification des randonnées

Classification : **Cœur**.

Définit le produit : choix du sentier, admissibilité du chef, calendrier, capacité et cycle de vie. Ces règles propres au club déterminent les événements proposés.

## Responsabilité
Créer, fermer et annuler une randonnée; parcourir les événements.

## Concepts candidats
Randonnée, statut, organisateur référencé, historique de transitions.

Ce livrable fixe la frontière du sous-domaine; il ne prétend pas fournir une implémentation. Voir le rapport pour les invariants et les dépendances.
