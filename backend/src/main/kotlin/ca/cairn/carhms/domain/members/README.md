# Profils et habilitations

Classification : **Support**.

Les profils, l’adhésion constatée et la certification alimentent les décisions du cœur. Le recrutement et la gestion administrative complète des adhésions restent externes.

## Responsabilité
Enregistrer un randonneur et mettre à jour son profil, son statut ou sa certification.

## Concepts candidats
Randonneur, coordonnées, contact d’urgence, décharge, certification.

Voir le rapport (section 5) pour les invariants et les dépendances.
